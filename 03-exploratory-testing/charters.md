# Charters

## Charter 1

**Título:** Validación de pedidos duplicados

**Misión:**  
Explorar el proceso de compra y confirmación de pedidos realizando reintentos y acciones repetidas, con el propósito de verificar si el sistema puede registrar un mismo pedido más de una vez y detectar posibles cobros o pedidos duplicados.

**Área principal explorada:**  
Proceso de compra y confirmación de pedidos.

## Charter 2

**Título:** Validación de disponibilidad de productos

**Misión:**  
Explorar el proceso de selección y compra de productos, observando el comportamiento del sistema ante productos con disponibilidad limitada o sin stock, con el propósito de identificar si permite completar compras de productos que realmente no están disponibles.

**Área principal explorada:**  
Catálogo, carrito de compras y disponibilidad de productos.
