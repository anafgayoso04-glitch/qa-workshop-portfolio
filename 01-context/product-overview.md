# Product Overview
## Nombre del producto
PetStore
## ¿Qué tipo de producto es?
Plataforma de comercio electronico orientado a la venta de mascotas,accesorios y alimentos.
## ¿Qué problema resuelve?
Permite que los clientes puedan consultar productos para mascotas y realizar compras de forma online, evitando la necesidad de acudir físicamente a una tienda.

## ¿Cómo genera valor para el negocio?
La plataforma permite ampliar el canal de ventas de la empresa, facilitar el acceso de los clientes a los productos y agilizar el proceso de compra.

## Usuarios principales
- Clientes
- Administradores de la plataforma
- Personal encargado de gestionar productos y pedidos
## Funcionalidades principales
- Consulta de productos disponibles
- Selección y compra de productos
- Gestión de pedidos
- Gestión de información de productos
- Gestión de clientes
